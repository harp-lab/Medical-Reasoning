## Which of these induce tremor?

This is the sharp, well‑defined part. One wrinkle worth flagging: the disease→gene edges use **HGNC** gene ids while the gene→tremor edges use **NCBIGene** ids, so a naive join finds nothing — I bridged the two id spaces via `same_as`/`close_match`. Of all the PD/AD‑associated genes, only **6 distinct genes** have an edge to *Tremor* (HP:0001337):

| Gene | Link to tremor | PD‑assoc. | AD‑assoc. |
|------|----------------|:---------:|:---------:|
| **HTR1A** (serotonin receptor 1A) | `causes` | ✓ | ✓ |
| **STUB1** (CHIP ubiquitin ligase) | `causes` | ✓ | ✓ |
| **APP** (amyloid precursor protein) | `predisposes` | ✓ | ✓ |
| **VIM** (vimentin) | `predisposes` | ✓ | ✓ |
| **SGCE** (ε‑sarcoglycan) | `affects` | ✓ | — |
| **EEF1A2** (elongation factor) | `affects` | ✓ | — |

**Reading it:**
- **Strongest ("causes" tremor):** HTR1A and STUB1 — both linked to *both* PD and AD.
- **Predispose to tremor:** APP (the classic Alzheimer amyloid gene) and VIM — both diseases.
- **Modulate ("affects"):** SGCE and EEF1A2 — PD side only. SGCE is the myoclonus‑dystonia gene, so the tremor link is biologically sensible; "affects" is a weaker/direction‑neutral claim than "causes."

These are biologically coherent (APP → Alzheimer's; SGCE/STUB1 → movement disorders with tremor).

Two caveats on method: the gene–disease predicate is broad (co‑association level, hence the large counts), and "induce tremor" here means any of `causes`/`predisposes`/`contributes_to`/`affects` edges to the *Tremor* phenotype. Want me to tighten either definition, or pull the full gene lists?
